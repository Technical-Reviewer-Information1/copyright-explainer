# Copyright Explainer Project Overview

## 目的
Streamlitで構築された著作権について学習するためのインタラクティブなWebアプリケーション。学生向けに著作権の基本概念、パブリックドメイン、引用ルール、ライセンスについて段階的に教育する。

## 技術スタック
- **フロントエンド**: Streamlit
- **可視化**: Plotly (グラフ用)
- **データ処理**: Pandas
- **言語**: Python

## 構造
- `streamlit_app.py`: メインアプリケーション
- `requirements.txt`: 依存関係
- 7ステップの段階的学習フロー

## 主な学習内容
1. 著作権の基本概念
2. ブログ作成での実践
3. 画像の著作権判定
4. BGM（音楽）の著作権
5. 引用の正しい方法
6. 著作者の権利
7. 私的利用の範囲

## 現在の問題点
- バッハ（1750年没）の著作権保護期間の描写が歴史的に不正確
- 著作権制度の発展時期と実際の法制史との齟齬
